# UW Notes

University of Waterloo course notes, written in **Obsidian-flavoured Markdown** (callouts, math, wikilinks, fenced code).

## Courses

- **[CS 136 — Complete Notes](Notes/CS%20136%20%E2%80%94%20Complete%20Notes.md)** — Elementary Algorithm Design & Data Abstraction (intro C)
- **[CS 245 — Complete Notes](Notes/CS%20245%20%E2%80%94%20Complete%20Notes.md)** — Logic and Computation
- **[STAT 230 — Complete Notes](Notes/STAT%20230%20%E2%80%94%20Complete%20Notes.md)** — Probability

Each course is a single file with a clickable **index** at the top, the full **topics**, and a per-chapter **glossary** at the end.

## How to use

- **GitHub web / phone:** open any file above to read it.
- **Best experience:** clone the repo and open the folder as an **Obsidian** vault — callout boxes, rendered math, and the in-file index links all work.

```bash
git clone https://github.com/Muhammad-Rayyan-Moosani/uw-notes.git
```
